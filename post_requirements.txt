POST /api/media/upload — Upload File(s)
Content-Type: multipart/form-data

files[]       (required) | file input — max 5 files, max 100MB each
              Allowed types: jpg, png, gif, webp, pdf, doc, docx, xls, xlsx, ppt, pptx,
                             mp4, avi, mkv, mp3, wav, zip, rar

title         (optional) | string — display title for the file
description   (optional) | string — file description
accessLevel   (optional) | enum: admin_only, all_staff, public — default: admin_only
tags          (optional) | comma-separated string OR array — e.g. "training,2025,q1"
